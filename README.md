# Bread

A small phone app for measuring and documenting bread recipes. Works on Android and iPhone as an installable web app (PWA): open the link once, add it to your home screen, and it runs full screen and offline from then on.

**Live app:** https://SinaVG.github.io/bread-app/

## What it does

- **Recipes** – keep each recipe as a list of ingredients in grams plus free-form method notes (water temperature, folds, proof, oven schedule, internal temperature, "next test"…).
- **Scale by loaf count** – type how many loaves you want and every amount is recalculated. The base recipe can be for any number of loaves (the sample is for 2).
- **Ratios** – each ingredient is shown as a baker's percentage (weight ÷ total flour), together with hydration, total flour, total dough and dough per loaf.
- **Bake journal** – log every bake: date, loaves, water temp, proof time, oven schedule, internal temp, a 1–5 rating, notes, what to try next time, and photos. The exact amounts used are saved with the entry.
- **Share** – send a scaled recipe as text to Notes, Messages, etc.
- **Backup** – export/import a JSON file (includes photos) to move your data to a new phone.
- **Offline** – everything is stored on the device; no account, no server.

The app ships with the Sandwich Bread recipe (68 % hydration, 2 loaves) that this project started from.

## Install on your phone

| Phone | Steps |
|---|---|
| iPhone / iPad | Open the link in **Safari** → tap **Share** → **Add to Home Screen**. |
| Android | Open the link in **Chrome** → tap **⋮** → **Add to Home screen** / **Install app** (or use the Install button inside the app). |

## Project layout

```
index.html            app shell
styles.css            styles (light + dark)
app.js                all logic: routing, scaling math, journal, backup, PWA hooks
sw.js                 service worker (offline cache)
manifest.webmanifest  PWA manifest
icons/                app icons (generated by tools/make_icons.py)
publish.ps1           one-shot GitHub repo + GitHub Pages setup
```

No build step and no dependencies. Open `index.html` through any static server, e.g.

```bash
python -m http.server 8765
```

then visit http://127.0.0.1:8765/.

## Publishing / updating

The app is hosted with GitHub Pages straight from the `main` branch.

First time (needs the [GitHub CLI](https://cli.github.com/) and `gh auth login`):

```powershell
.\publish.ps1
```

Later updates:

1. Edit the files.
2. Bump `VERSION` in `sw.js` (so phones pick up the new files) and `APP_VERSION` in `app.js`.
3. Commit and push to `main`. Pages redeploys in about a minute; installed apps show an "Update ready" toast on next launch.

## Data model

Stored in `localStorage` under `bread.v1`; photos in IndexedDB (`bread-photos`).

```jsonc
{
  "recipes": [{ "id", "name", "baseLoaves", "ingredients": [{ "name", "grams", "role": "flour|liquid|other" }], "notes": [{ "label", "value" }] }],
  "bakes":   [{ "id", "recipeId", "date", "loaves", "waterTemp", "proofTime", "oven", "internalTemp", "rating", "notes", "nextTime", "photoIds", "snapshot", "hydration" }]
}
```

Hydration = liquids ÷ flours. Baker's % = ingredient ÷ total flour × 100.
